# 総合HPの写真表現 3案 / 2026-09-22

本人がまとさんの参考を選び、複数パターン制作を依頼。まず写真と画像の扱いを比較できる3案を制作する。

共通の目的：AI導入と強みの読み解きに興味を持ち、該当する入口へ進める。本人の公開プロフィールと既存のリンクを使い、料金・実績・お客様の声を新しく創作しない。

## A / Studio（まとさんの構成を優先してTTP）

参照 https://x.com/MatoToushi/status/2099660833609638059 。オフホワイト、中央の短い見出し（約48px）、小さな濃色ピルCTA、下段の本人＋写真風AIオブジェクト。画像は約960px幅、人物中心、左右に素材。背景#faf9f6、文字#2b302c、差し色#cc785f。見出しは明朝、本文ゴシック。人物画像は静止、周辺の小要素だけ緩やかに動く。

## B / Landscape（天川村＋Archi Greenから）

参照 https://www.vill.tenkawa.nara.jp/tourism/ と Inspo保存Archi Green。緑を望む明るい森のアトリエ。画面幅の写真、左に文字、右に建物・木々。写真上の文字背景だけ暗くする。白い大きめの明朝見出し、写真の下は生成り。写真をゆっくり拡大、動きを減らす設定では静止。

## C / Editorial（写真と余白を左右に分ける）

写真の明暗へ文字の可読性を依存させず、左側に大きい見出しと本文、右側に自然光の机の写真。生成り#f3f0e8、墨緑#244239、朱#b56142。大きい番号と罫線を使って2つのサービスを案内。本文18px前後、セクション余白100px。本人写真は自己紹介に原写真を使う。

## 実装・確認

3ページの内容・リンクは揃え、色替えだけでなく構図と情報の順番を変える。写真はAI生成のコンセプト画像であり、実在の事務所・活動風景を写したものとは表示しない。本人の顔を使うAは参照写真から合成し原写真も保持。
共通比較UIで3案、既存v1/v2を選択。スマホ390pxとデスクトップ、ページ内リンク、実画像ロード、キーボード操作、reduced-motion、HTML可読テキストを確認。GitHubの試作ブランチへ保存し本番mainへ反映しない。
