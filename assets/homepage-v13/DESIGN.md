# v13 画像の重複解消と具体的な業務の説明

本人の指摘: 写真の使い回しをしない。画像が何を表すか不明、現場の仕事のしやすさとの関係が見えない。
対象: 総合とAI現場伴走室で重複していたteam.webpの両配置。各々専用の新規画像へ。強み整理・ケア対話の画像は独立用途で各一度、本人写真とブランドアイコンは本人紹介/識別用途。
総合: 少人数の職員が自分でPCを操作する実務研修。講師が一方的に話す姿や単なる相談写真を避ける。キャプションで実際の仕事を題材にした研修と明記。
伴走室: 手元のメモを見ながらPCの下書きを確認する職員の肩越し。文章の変換を画像の雰囲気だけに任せず、HTMLの3段階と架空の短い例を添える。個人情報・患者記録・成果数値なし。
保つ: 浮遊トップ・既存配色・親しみ・具体的な支援内容。新画像は横3:2、写真風、自然光、木と深緑。AIイメージ明記。
受入: 本文の場面画像4配置がすべて異なる実ファイル/ハッシュ。新画像が研修/下書き確認の別場面として読める。PC/390pxで可読。版保存、本番反映とは区別。
