# v8 — a breeze through Okemon's studio

本人の「2体の上下動だけでは弱い。素材と流れを掛け合わせ、本人らしく、おしゃれに」という依頼への改修。

- 実際に確認した参考: https://x.com/MatoToushi/status/2099660833609638059 。2026-09-22にログイン済みChromeで投稿本文・4.281秒の再生中動画を確認。大小の素材密度と人物の前後の構図を参考にした。第三者の画像・実装をコピーしていない。原サイトの公開URLは未確認。
- 固有の構成: カピバラ＋PC、インコ＋コンパス、既存の海辺アトリエ写真の小窓、新規の透過ガラスの芽、紙のメモ・紙飛行機、ガラス玉と種。
- 動き: 14要素。キャラの斜め移動・回転、写真窓と紙の緩い姿勢変化、種の漂い、2本の曲線に沿う光を、7.8〜18秒の異なる周期で合成。人物・見出しは固定。
- 素材: built-in image_genのガラス芽を原本PNGと透過WebPで保存。RGBA 1254×1254、alpha 0–255、WebP 123,532 bytes。プロンプトはPROMPTS.md。キャラ・人物の画像ファイルは変更なし。CSSとSVGで小さな図形・紙飛行機・軌道を実装。
