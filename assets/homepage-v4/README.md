## v6 floating / 2026-09-22

本人の「魅力はふわふわ浮くトップ画像だった」という修正を受けて実装。v4は小さい装飾の丸のみ動き、本・ロボットの本体は1枚の静止画像だった。人物と左右の小物を同じ原画像からCSS clip-pathの独立したDOMレイヤーとして表示し、左右を6.4秒／7.6秒の異なる周期で上下・小角度回転させる。顔・画像ファイルの再生成はしていない。左右は小物のまとまり単位で、個々の本やカードを完全に分離した素材ではない。

停止・再開ボタンを追加。画面外ではIntersectionObserverで停止し、手動停止状態はスクロールしても維持。prefers-reduced-motionでは元の静止画像を表示し、非対応ブラウザーにも静止画を残す。Web上のCSS演出として実装し、動画の自動再生や音は使用しない。

QA: 320/390/768/1440pxで画像ロード・横はみ出しなし。PC/スマホの画像境界を画面確認。時間を離して左右のtransformの変化を観測し、人物は常にnone。停止後の2回の観測ではtransform一致、再開後はrunningかつ位置変化。画面外はpausedを観測。スマホで停止ボタンが人物に重なった点を修正。低モーション分岐はCSS確認、OS設定を切り替える実測は未実施。原投稿のWAD記事面は静止作例を確認、まとさん動画は今回再訪時にホームへ遷移し動画自体の再観察はできていないため、今回の動きの受入条件は本人が指定した浮遊感。
