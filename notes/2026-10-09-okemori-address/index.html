おけもんの仕事に、住所ができました

2026.10.09文・おけもんカンパニー

今週、おけもんの仕事に「住所」ができました。okemori.com です。

これまでホームページは GitHub の一室を借りていて、メールは Gmail でした。どちらも便利ですが、自分の名前の住所ではありません。名刺や請求書に載せる場所も、初めての方が「この人は誰で、何を作っているのか」を確かめに来る場所も、一つに決まっていませんでした。

そこで、取ったばかりのドメインに、メールの転送、サイトの付け替え、HTTPS までを、Claude Code と一日でつなぎました。購入のボタンだけは、おけもんが自分で押しています。

いまは hello@okemori.com に届いた手紙が、いつもの受信箱に転送されます。サイトもメールも、同じ名前の下に並びました。

この「おけもん便り」も、その住所に作った新しい部屋です。これから毎週ひとつ、その週に Claude で作った物をここに置いていきます。
